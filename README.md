# Alex Lewis

Personal website for Alex Lewis: creative strategy for experiences and places.

## Structure

- `dist/index.html` — site content and structure
- `dist/site.css` — visual system and responsive layout
- `dist/assets/` — project imagery
- `netlify.toml` — Netlify publishing and security settings

## Publishing

Connect this repository to Netlify and leave the build command blank. Netlify reads `netlify.toml` and publishes the `dist` directory.

Changes merged into the production branch will deploy automatically.
